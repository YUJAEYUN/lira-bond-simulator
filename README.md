# 미국채 + 리라채 수익 시뮬레이터

법인이 미국채를 사고, 달러를 더 빌려 터키 국채(리라채)에도 투자했다면 원화로 얼마를 벌었을지
과거 데이터로 계산해 보는 Streamlit 앱입니다.

- **전략 A**: 원화를 달러로 바꿔 미국채 1년물만 보유
- **전략 B**: 전략 A에 더해, 달러를 빌려 리라로 바꾼 뒤 리라채 1년물도 보유

B에서 A를 뺀 값, 즉 리라채를 얹어서 더 번(또는 잃은) 돈을 "알파"라고 부릅니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

데이터는 `dataset/`에 있는 원/달러·리라/달러 환율과 미국채·터키 국채 1년물 금리입니다.
기간은 2023-01-02부터 2026-04-27까지이고, 앱에서 "현재"는 이 마지막 날짜를 뜻합니다.

## 핵심 개념: 손익분기 하락률

리라채 금리가 높기 때문에 리라가 어느 정도 떨어져도 이자로 메울 수 있습니다. 메울 수 있는
한계는 다음과 같습니다(`t`: 보유 햇수, `r`: 대출금리).

```
손익분기 하락률 = (1 + r × t) / (1 + 리라채 금리 × t) − 1
```

리라가 달러 대비 이보다 덜 떨어지면 알파는 플러스, 더 떨어지면 마이너스입니다. 리라채 금리가
35~47%일 때 1년 손익분기 하락률은 약 −25~−28%입니다.

## 시뮬레이션으로 알게 된 점

수치는 기본 설정(대출금리 6%, 레버리지 50%)이고, 수익률은 투자원금 대비입니다.

### 1. 리라 이자가 원화 강세를 받쳐 준다

원화로 투자하는 법인에게 미국채의 가장 큰 위험은 원/달러 하락(원화 강세)입니다. 달러로 받은
원금과 이자가 원화로 줄어들기 때문입니다.

알파가 플러스인지 마이너스인지는 원/달러와 상관없이 리라/달러 환율만으로 정해집니다. 원/달러는
손익의 크기만 바꿉니다. 그래서 원/달러가 떨어져 미국채 수익이 줄 때도 리라 이자가 따로 수익을
더해 줍니다.

- 2025년 1월 진입: 원/달러가 2.0% 떨어져 전략 A는 +2.1%에 그쳤지만, 알파 +5.0%가 더해져 전략 B는
  +7.0%였습니다.
- 1년 동안 원/달러가 떨어진 진입일 79개 중 96%에서 알파가 플러스였습니다.

다만 이 기간에 원/달러가 1년 동안 가장 많이 떨어진 폭은 3.1%였습니다. 원화가 크게 강해지는
상황은 이 데이터로 확인하지 못했습니다.

### 2. 이자로 버틸 여유는 크지만, 한 번의 급락에는 무너진다

2024~2025년에는 리라가 한 해 16~18%씩 천천히 떨어졌고, 이자가 이 손실을 충분히 메웠습니다.

2023년 초 진입은 달랐습니다. 6월 터키 대선 뒤 리라 가치가 한 달 만에 약 20% 떨어졌고, 그해
모두 36.5% 떨어져 손익분기점을 넘었습니다. 진입일을 하루씩 옮겨 가며 계산해 보면, 2023년 1~5월
진입은 거의 다 손실이었고 급락 뒤인 7월 이후 진입은 모두 수익이었습니다.

### 3. 대출금리보다 진입 시점과 레버리지가 중요하다

대출금리가 1%p 오르면 알파는 약 0.5%p만 줄어듭니다. 리라채 금리와 대출금리 차이가 30%p가 넘기
때문입니다. 레버리지는 알파를 비례해서 키웁니다(2024년 1월 진입: 10%에서 +1.9%, 100%에서 +19.4%).
레버리지는 이기고 지는 방향이 아니라 얼마나 크게 거느냐를 정합니다.
